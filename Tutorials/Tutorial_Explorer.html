1.2 The 95% Token Sparsification Mechanism

Before deep processing, the system aggressively prunes the input matrix. A uniform random mask is applied, dropping exactly 95% of the patch tokens (\(\rho = 0.95\)).

Not Tube Masking

Unlike structured "tube masking" which occludes continuous regions, uniform random dropping forces the remaining 5% of tokens to act as sparse semantic mass nodes.

This shifts the computational burden from exhaustive volumetric pixel evaluation \( O((R/h)^3) \) to a highly efficient sparse graph traversal \( O(|V| \log |V|) \).

1.3 Block-Causal Attention Encoding

The sparse 5% token set is fed into the shared LeVJEPA Vision Transformer. Self-attention is configured to be block-causal: tokens attend bidirectionally within their current frame, but strictly backward in time to preceding frames.

The Objective Function

A single encoder is trained with an invariance loss over global and local views, regularized by SIGReg to provably exclude collapse:

\[ \mathcal{L} = \mathcal{L}_{inv} + \lambda \mathcal{L}_{SIGReg} \]

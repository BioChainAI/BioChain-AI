# Nested Harmonic Cocoon

The Harmonic Cocoon subsystem of BioChain AI. Everything lives in
[`biochain_cocoon/`](biochain_cocoon/README.md), a self-contained monorepo
(firmware, hardware, orchestrator, deploy, protocols, presets, docs) that
runs standalone and optionally synchronises with the BioChain protocol stack.

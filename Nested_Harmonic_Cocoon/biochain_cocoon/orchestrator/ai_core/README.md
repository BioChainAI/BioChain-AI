# ai_core/: cocoon_ai (the Guide)

Deterministic, explainable, and dependency-free. Biofeedback → `BioState` →
hyperbolic distance to the target state → `GeoCommand`s, each with a rationale.
The policy interface is in `docs/api_reference/ai_core_policy.md`. It is the
plug-in point for hyperbolic models trained in the BioChain AI ecosystem.

# docs/

| folder | read it when |
|---|---|
| `architecture/` | you need the *why*: the original concept specs, how the cocoon syncs with BioChain while staying standalone, safety, and the design decisions log |
| `hardware_assembly/` | you are building pucks: soldering order, bring-up and self-tests per node |
| `api_reference/` | you are integrating: orchestrator HTTP API, firmware `shared_core` API, AI core policy interface |

Protocol-level specs (byte maps, pi6, kernel mapping) live in `../protocols/docs/`.
